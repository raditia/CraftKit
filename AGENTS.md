# CraftKit repository guidance

This repository distributes instructions to Claude Code, Cursor, Gemini CLI, and Codex. Edit source files in `rules/`, `skills/`, `commands/`, `agents/`, `partials/`, `adapters/`, or `hooks/`. Installed copies in home directories are generated by `sync.sh`.

Before editing, check for overlapping instructions in the source directories. Keep shared guidance in one place and update the README when a rule, skill, command, or agent is added, removed, or renamed.

Run `bash check.sh` after a change. Then run `bash sync.sh` twice: the first run must finish successfully and the second must report everything up to date. These commands update the local installed copies.

The scripts must work with Bash 3.2. The root `CLAUDE.md` contains the full architecture and authoring checklist; consult its relevant section when changing distribution behavior.
